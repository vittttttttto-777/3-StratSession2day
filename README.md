## Дерево бизнес-метрик и справочник функций

Конструктор (слайд «Строим своё дерево») связан со справочником функций дня 1 (`vs_functions`):

- **Функция-владелец** метрики выбирается из справочника. Старые деревья, где владелец записан текстом
  («ДПД», «МК», «EC»), привязываются автоматически; нераспознанное (например, «КМ») остаётся текстом
  с подсказкой выбрать функцию.
- **Влияют на метрику** — любое число функций из справочника.
- Цветная точка у функции — тип по анкете: зелёная — центр дохода, жёлтая — центр сервиса,
  красная — центр экспертизы. Тип задаёт администратор в приложении дня 1, вкладка «Справочник функций».

Если справочник недоступен (нет связи с базой), владелец вводится текстом, как раньше.

## Выгрузка в Excel

Кнопка **«Скачать Excel»** над деревом собирает файл:

| Лист | Что внутри |
|---|---|
| Дерево метрик | текущее дерево: уровень, метрика, тип, формула, роль в формуле родителя, рост %, владелец, тип владельца, влияющие функции, путь |
| Все деревья | все деревья, сохранённые в базе (слоты команд и CCI), одной таблицей |
| Функции × метрики | по каждой функции справочника: какими метриками владеет и на какие влияет; центры дохода без метрик подсвечены |

Библиотека `vendor/exceljs.min.js` (ExcelJS 4.4.0, MIT) подгружается при первом нажатии.

## Данные в базе

| Объект | Содержимое |
|---|---|
| `strat3_trees` | текущее дерево по слотам (HealthOS, GrowthModel, PrimeGrowth, CoralEVO, ITModel, CCI) |
| `strat3_tree_history` | история версий (не чаще раза в минуту) |
| `strat3_tree_metrics` | представление: деревья построчно с владельцами и влияющими функциями из `vs_functions` |

Узел дерева в JSON: `{id, n, ne, k:'b'|'o', op:'mul'|'add', g, sg, own, fo, fi:[], c:[]}`,
где `fo` — id функции-владельца, `fi` — id влияющих функций, `own` — владелец текстом (для старых деревьев).
